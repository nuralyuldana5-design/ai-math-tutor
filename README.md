# AI Math Tutor

A Grade 7 linear-equation practice web app with Foundation, Standard and Advanced difficulty levels, AI-generated hints, and worked solutions.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Add `GEMINI_API_KEY` to Streamlit Secrets (or an environment variable). Do not commit API keys to GitHub.

## Deployment

Deploy `app.py` on Streamlit Community Cloud and add `GEMINI_API_KEY` under the app's **Settings → Secrets**.

## Academic note

Review the prompts, test each level and verify the algebra before submission.
